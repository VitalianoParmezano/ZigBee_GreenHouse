# 🌿 Zigbee GreenHouse (ESP32-H2)

Прошивка ESP32-H2 для керування теплицями (клієнт-серверна архітектура).


## Архітектура

Головна концепція полягає в клієнт-серверній архітектурі. Мікроконтролер локально не зберігає у власній пам'яті дані, лише 75% при оффлайн режимі. Уся логіка знаходиться на вижчих рівнях (Z2M / HA / LogicService), есп лише керує яскравістю

Прошивка написана на C з використанням ESP-ZIGBEE-SDK та розбита на незалежні модулі. Головний вузол ініціалізації Zigbee-мережі знаходиться у файлі `main/esp_zb_switch.c`.

| Компонент | Опис та призначення |
| :--- | :--- |
| **`greenhouse_light_control`** | Відповідає за створення ендпоінтів, їх ініціалізацію. А також за ledstrip. |
| **`modbus`** | Модуль трансляції протоколу modbus. Виконує роль Modbus RTU Master для конвертації бездротових Zigbee-команд у сигнали для драйверів освітлення. |
| **`heart_beat`** | Модуль реалізовує перевірку з'єднання з координатором. Кожні 50 + rand(20) секунд надсилає boot_status 2 після чого чекає на 1 |
| **`light_driver`** | Звідси відбувається безпосереднє керування освітленням, він надсилає дані по modbus і на ledstrip, у майбутньому і інші протоколи. |
| **`reset_configuration`** | Апаратний контроль конфігурації через DIP-перемикачі. Дозволяє фізично задавати номер групи або виконувати Factory Reset при натиску на кнопку 5 секунд. |


## Структура Ендпоінтів

Контролер реалізує нестандартні Zigbee ендпоінти і рішення для підтримки n зон по 3 канали кожна. Логіка наступна: ендпоінти каналів лежать починаючи з 11, тобто ендпоінт 12 це ендпоінт 2 каналу. Ендпоінт 2 у цій версії має лише атрибут boot_status, який використовується для сигналу heart_beat 

| Endpoint (EP) | Кластер (Cluster) | Атрибут (Attribute) | Опис функції |
| :--- | :--- | :--- | :--- |
| **EP 1** (System) | - | - | Базові атрибути потрібні для роботи Zigbee stack (назва моделі, опис ...) |
| **EP 2** (MetaData) | `0xFF01` (Custom) | `boot_status` 0x0000 | Статус початкової синхронізації, якщо == 0, тоді відбудеться синхронізація. |
| **EP 11** (Z1, Ch1) | `0x0008` (Level Control) | `current_level` 0x0000 | Поточна яскравість (0-254) першого каналу першої зони. |
|  | `0x0006` (State) | `State` 0x0000 | Стан on\off. |
| **EP 12** (Z1, Ch2) | `0x0008` (Level Control) | `current_level` 0x0000 | Поточна яскравість (0-254) другого каналу першої зони. |
|  | `0x0006` (State) | `State` 0x0000 | Стан on\off. |
